# Personal Objects — Portfolio prototype

A blue spatial portfolio prototype with five interactive Three.js objects. Personal information and project content are placeholders.

## Preview
Serve this directory using any static HTTP server. No build step or package installation is required. Three.js is vendored locally.

## GitHub Pages
The included workflow deploys the `main` branch. In repository Settings → Pages, set Source to **GitHub Actions**, then push or manually run the workflow.

## Scope
Homepage interaction prototype only. No complete project detail pages. Camera, folder, sketchbook, resume and envelope are simplified original geometry.

Third-party library: Three.js 0.160.1, MIT license (see LICENSE-three.txt).
